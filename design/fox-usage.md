# Fox usage — the MaxiFox logo and מקסי השועל (Maxi), per screen (360x800, RTL)
Art is approved and fixed; never recolour, redraw or stretch it (keep aspect ratio, `height` driven, `width:auto`). All sizes in CSS px. Positions use logical properties (`inset-inline-start` = right in RTL).
Files: `src/assets/fox/`. Cutouts are transparent, ship `@2x`; use `srcset="x.webp 1x, x@2x.webp 2x"` (only `tired`, `wave`, `roll`, `hammock`, `tip` have @2x). Reaction crops (`think`, `celebrate`, `worried`, `ponder` .webp, 512x512) have a navy background baked in, so they are ALWAYS shown as a circle crop with a 3px gold ring (`border-radius:50%; border:3px solid var(--c-gold-400)`), which matches the art's own gold-ring motif.
`hero.webp` (1254, orange) is for in-game character art only (guide, win sharing). Splash, home, icons and store use the gold MaxiFox logo (section below).

Common motion tokens: idle bob = `translateY(calc(var(--bob-height) * -1))` over `--dur-bob` (2400ms) ease-in-out infinite; entrance = fade + 24px rise over 400ms `--ease-out`; reaction pop = `--dur-pop` (320ms) `--ease-bounce`, visible `--dur-toast` (2200ms), exit 180ms `--ease-in`. Under `prefers-reduced-motion` / `data-motion="reduced"` the tokens collapse: no bob, no rise, 120ms fades only. Every fox image is `alt=""` when decorative, or a short Hebrew alt when it carries meaning (start/win).
Shadow under every fox cutout: `filter: drop-shadow(0 12px 16px rgb(0 0 0 / .45))`. Halo behind hero poses: `--glow-fox` radial, about 1.1x the fox height.

## Logo vs character (rename 2026-10-23, docs/decisions.md)
Two different foxes, two different jobs. Never put both on one screen at the same visual weight, never recolour one into the other.

| | **MaxiFox logo** (brand) | **מקסי השועל / Maxi** (character) |
|---|---|---|
| Look | gold fox head, sunglasses, gold ring on navy, "MaxiFox" wordmark | orange fox, cream muzzle, gold-frame sunglasses, navy jacket (the approved poses in `src/assets/fox/`) |
| Source | `design/brand/maxifox-logo-source.jpg` (used as is, never redrawn or retyped) | `design/character/` reference art |
| Appears on | app icon + favicon, home (start) screen, splash, store listing and feature graphic, share images | the guide (first game, 'מקסי מסביר', dictionary), feedback notes and family tips on the board, win (hammock), game over (tired, supportive) |
| Voice | none (it never speaks, never reacts) | speaks in the first person: "היי, אני מקסי!", "מקסי אומר", "מקסי מסביר" |
| Motion | entrance fade/scale only | bob, pop, wave, sway (table below) |

Files (generated by `design/brand/scripts/`, see the end of this file):
- Full logo with wordmark: `design/brand/maxifox-logo-alpha-1x.webp` (240w) / `-2x.webp` (480w), navy removed. **Use these in the app on both themes.** Opaque versions `maxifox-logo-1x/2x.webp` keep the source navy `#0A1C3A`; they show a visible box on the app's `#0F172A`, so use them only on an exact `#0A1C3A` ground or in print/store art.
- The alpha keeps the navy disc inside the gold ring and the navy jacket (both are part of the art); only the navy around the ring, between the ears and around the letters is removed. The jacket fades out above the wordmark. On the light theme (`#FBF3E1`) the result reads as a navy badge with a gold wordmark; checked in `design/brand/icons-contact-sheet.png`.
- Mark without wordmark (icons only): `public/icons/*`, `design/brand/android-foreground-432.png`.

### Clear space
- Unit **X = 1/6 of the full logo's width** (≈ the cap height of the "M"). Keep X free on every side: no text, buttons, edges or other art inside it. At 200px wide on home that is 33px.
- Mark (icon art without wordmark): keep 8% of the ring diameter free around the ring and ears. Maskable and adaptive icons get this from the platform safe zone (art inside the 80% circle / the 66dp circle).
- Do not put the orange character inside the logo's clear space.

### Minimum size
- Full logo with wordmark: **120px CSS wide** on screen (the "M" is then ~20px); 25mm in print. Below that, use the mark.
- Mark: 48px for the ring version; at 16-32px use only `favicon-32.png` (a tighter face crop, ring partly clipped, so the sunglasses read).

### Don'ts
- No redrawing, retyping the wordmark in another font, recolouring, stretching, rotating, outlines or extra glows.
- No logo on orange, gold or busy photo grounds; navy or cream only.
- Never colour the character gold or the logo orange.
- The logo is not a button and has no `alt` beyond the name: home `h1` accessible name "MaxiFox", image `alt=""`.

## Rules of thumb
- One fox per screen at a time (hero pose OR a circle crop). On the board (v4) there is exactly one fox: the corner guide. The big poses and the halo stay on home, profession pick and win (and game over).
- Fox is decoration, not an input, everywhere except the board corner guide (v4), which is a real button that re-opens the last message (48px+ hit area by its size). Any tap target nearby keeps its own >=48px box; the start screen tap-squash is non-essential.
- Reaction circles and bubbles never carry information that is not also in text elsewhere (HUD, card, status line or log); bubbles are `role="status"`, the guide image is `aria-hidden`.
- Preload `maxifox-logo-alpha-2x.webp` on the start screen (it is the LCP image; replaces the `tired`/`wave` preload in vite.config.js) and `roll@2x`; lazy-load `hammock@2x`, `tip@2x` and `wave@2x`.
- Regenerate the brand files: `python3 design/brand/scripts/alpha.py <tmpdir> && python3 design/brand/scripts/build.py <tmpdir> && python3 design/brand/scripts/sheet.py` from the repo root. Do NOT run `npm run icons` (scripts/make-icons.*): it still rebuilds the icons from the old orange hero and would overwrite the MaxiFox icons.
