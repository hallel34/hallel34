# Financial literacy design

## Principles
1. **One concept at a time.** Introduce a term the first time it matters, in one sentence plus "why it matters". Never stack concepts.
2. **Guess before explaining.** Ask the player to judge ("עסקה טובה?") before showing the verdict; reveal the numbers and a traffic light after.
3. **Instant, reasoned feedback.** After each decision, one line from the fox that names the number behind the verdict ("החזר ב-4 שנים — מצוין"). Never vague praise.
4. **Mistakes are cheap, shame is banned.** Supportive tone, never mocking; the fox is a savvy friend.
5. **Honest simplification.** Separate a game simplification ("במשחק המספרים מפושטים") from a real-world fact ("בעולם האמיתי…"). Never present a simplified number as reality.
6. **No get-rich promises.** Passive income is a goal that takes time and has risk; mention risk, diversification and a safety cushion. No investment advice.
7. **Real numbers, real sources.** Every "in the real world" fact has a source and a date; finance verifies it.
8. **Age 9+ language.** Short sentences, concrete examples with game numbers, plural/gender-neutral phrasing, Hebrew-first RTL.

## Checks before shipping any lesson
- Is each sentence true? Is the simplification labelled?
- Does it teach exactly one concept?
- Can a 9-year-old read it in 10 seconds?
- Does the game's math agree with what the text says (interest, payback, cash flow)?
