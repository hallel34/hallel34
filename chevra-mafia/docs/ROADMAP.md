## 🔴 עדיפות גבוהה
- [ ] **העברת מארח:** אם המארח מתנתק באמצע, המשחק נתקע. צריך heartbeat ובחירת מארח חדש.
- [ ] **הסתרת תפקידים:** כרגע כל התפקידים יושבים במסמך החדר וגלויים ב-DevTools. האפשרות היא להעביר אותם לתת-מסמכים פרטיים עם Firebase Anonymous Auth ו-Rules.
- [ ] **Rules מאובטחים:** כרגע כולם יכולים לכתוב הכל.
