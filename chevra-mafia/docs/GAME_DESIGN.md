# חברה – מסמך עיצוב משחק (מקור אמת)

## תפקידים
| תפקיד | פעולת לילה | צד |
|---|---|---|
| מאפיונר 🔪 | בוחרים קורבן יחד. נדרשת הסכמה של כל המאפיונרים החיים | מאפיה |
| רופא 💉 | מגן על שחקן אחד, אפשר גם על עצמו | עיר |
| בלש 🔍 | בודק שחקן אחד ומקבל תשובה "מאפיה" או "לא" מיד | עיר |
| אזרח 🏠 | אין | עיר |

## הגדרות (מארח)
- מספר מאפיונרים: בין 1 ל-6, ובתנאי ש-`mafia*2 < players`.
- רופא ובלש: כל אחד מהם אפשר להפעיל או לכבות.
- זמן דיון: 1, 2, 3 או 5 דקות.
- מינימום 4 שחקנים, מקסימום 20.

## שלבים (`status`)
`lobby` → `reveal` → `night` → `day` → `vote` → `voteResult` → `night` → …   → `over`

- **reveal:** כל שחקן חי מסמן "מוכן". כשכולם מוכנים, מתחיל לילה 1.
- **night:** הלילה נגמר כשהמאפיה הסכימה על קורבן, והרופא והבלש (אם הם בחיים) בחרו.
  - הקורבן מת, אלא אם הרופא הגן עליו. אחר כך בודקים ניצחון.
- **day:** טיימר. כשהוא נגמר, או כשהמארח מקדם ידנית, עוברים ל-vote.
- **vote:** כל שחקן חי מצביע על שחקן חי אחר או על "דילוג". ההצבעה נגמרת כשכולם הצביעו, או כשהמארח מסיים אותה.
  - המודח הוא מי שקיבל הכי הרבה קולות, ובלבד שאין תיקו ושהמוביל אינו "דילוג". אחרת אף אחד לא מודח.
  - התפקיד של המודח לא נחשף עד סוף המשחק.
- **ניצחון** (נבדק אחרי לילה ואחרי הצבעה):
  - העיר מנצחת כשאין מאפיונרים חיים.
  - המאפיה מנצחת כשמספר המאפיונרים החיים גדול או שווה למספר שאר החיים.

## מודל נתונים – `rooms/{code}`
```js
{
  code, hostId, status, round, createdAt,
  settings: { mafia, doctor, detective, discussion },
  players: { [pid]: { name, joinedAt, alive, role, ready } },
  night:   { mafia: { [pid]: targetId }, doctor, detective },
  votes:   { [pid]: targetId | 'skip' },
  checks:  { [round]: { target, mafia } },
  dayResult:  { killed, saved, round },
  voteResult: { out, votes, round },
  dayEndsAt, winner: 'town' | 'mafia' | null, lastEvent
}
```
- `pid` הוא מזהה אקראי שנשמר ב-localStorage, ולכן רענון של הדף מחזיר את השחקן לחדר.
